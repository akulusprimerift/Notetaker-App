# Course materials before Windows delivery

Date: 2026-09-08. User-requested scope brought forward from Phase 7.2 before M08.

Implemented: course syllabus/curriculum uploads apply to existing and future lectures; lecture uploads add slides before or after recording. PPTX, DOCX, text-based PDF, UTF-8 TXT and Markdown are accepted. Originals and extracted excerpts are immutable database records. Migration 0010 pins material IDs in immutable settings. Changed settings cancel stale note attempts and schedule streamed reconstruction using transcript and material sources. Student revisions retain compare/keep/merge/replace/undo; saved final snapshots and old exports remain immutable. Source inspection and exports distinguish uploaded evidence from audio. Lecture deletion removes lecture-scoped materials; course materials remain shared course evidence.

Limits are visible: 8 MiB per upload, 300 input slides, 180,000 text characters, 20 materials at the upload scope. Excerpts are bounded to 3,000 characters. Images, diagrams, speaker notes, embedded objects, scanned PDFs and legacy PPT are not interpreted. PPTX presentation relationships determine order. ZIP expansion and XML declarations are bounded/rejected. No external parser service, inference fallback or model download is used. The original canonical schema remains pinned for historical evaluation reproducibility; the materials schema extends the evidence labels for runtime generation.

Executed on this Windows development workspace: 147 backend tests passed, one service-only test skipped; 60 JavaScript contracts passed after preserving the historical schema; frontend type checking, lint and production build passed; Ruff passed. Chromium integration passed with an actual upload, extracted-text inspection and streamed regeneration while a protected student draft remained open. Dedicated material tests exercise idempotency, stale counts, CSRF, course inheritance, old exports, proposal replacement, source inspection, stale running attempts and tombstone deletion. The final extraction-order follow-up passed its targeted regression check. A subsequent follow-up adds a separate extraction process with a 20-second timeout, PDF text extraction, and pairing of transcript/material evidence within bounded batches. Six material tests pass, including a real synthetic PDF and a larger mixed-evidence batch. Ten materials/streaming regression tests passed before the final two cases were added. PostgreSQL then passed all 148 pre-PDF tests and real object/broker probes. These are synthetic engineering checks, not educational quality or desktop release qualification.

Representative lecture usefulness, microphone hardware, endurance, clean-machine installation and coordinated restore remain unqualified.
