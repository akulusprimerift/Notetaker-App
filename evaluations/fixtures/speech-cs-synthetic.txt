Binary search requires a sorted array. Distinct elements alone are not sufficient. We keep a lower bound and an upper bound on the remaining search interval. At each step, compare the target with the middle element. If they are equal, return that position. If the target is smaller, move the upper bound to the position before the middle. Otherwise, move the lower bound to the position after the middle. The loop invariant is that any matching element must remain inside the search interval. Each iteration removes about half of the remaining candidates. Therefore the time complexity is logarithmic, and the iterative implementation uses constant extra space. A linear scan is different: it may inspect every element. Do not confuse logarithmic time with constant time. For an empty array, return not found. For repeated values, ordinary binary search may return any matching position, not necessarily the first. Finding the first occurrence requires continuing toward the left after a match.
