01

FIRST, GET READY

Local services

Create a standalone library to use bundled Windows services without Docker, Python or PowerShell. Your existing Docker library stays separate and can still be opened below. Choose local model files before recording; model weights are never downloaded.

Checking services…

Hiding the app keeps processing. Quitting pauses standalone processing until you reopen it. App data and recovery drafts are kept in your Windows user profile. Uninstalling the app retains them.

02

THEN, CHECK YOUR MODELS

Models on this computer

Installed Ollama models appear in a lecture’s note chooser. Speech recognition uses a local faster-whisper folder. Detected files are listed for reference only; Notetaker never imports or downloads them automatically.

03

Your first lecture, step by step

  1. Choose a speech model folder above. It must contain model.bin, config.json and tokenizer.json.
  2. Create your standalone library, or choose your existing Docker workspace. If you changed the model while services were running, pause and start them again.
  3. Open the workspace, add a course and a lecture, then choose an installed local note model in Note preferences. Install a compatible model with Ollama separately if none is available.
  4. Open Capture, select your input, and start recording. Wait for confirmed audio saves before quitting.

Next time, your saved library starts automatically. You can return here through Workspace settings.
