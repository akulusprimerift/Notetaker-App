Local services

The Windows app requires Docker Desktop with Linux containers, PowerShell 7, and Ollama for note generation. First startup builds the application services and may download software dependencies. It never downloads model weights.

Checking services…

Services continue processing when this window closes. Audio and database files remain in Docker volumes; window settings and recovery drafts remain in your Windows user profile. Uninstalling the app retains these files.

Models on this computer

Installed Ollama models appear in each lecture’s model chooser. Other detected files are listed for reference; they are not automatically imported or used.
